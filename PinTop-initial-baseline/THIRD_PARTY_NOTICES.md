## Initial import policy

The initial baseline intentionally excludes:

- compiled `.chm` help files
- the old NSIS installer script
- the deprecated `dphook` global hook DLL source
- `_misc` experiments and development utilities

These files can be reviewed separately if needed, but they are not required for the first PinTop modernization pass.
